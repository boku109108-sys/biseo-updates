# 업무비서 업데이트

업무비서(개인용 업무 보조 프로그램)의 **설치 파일과 자동 업데이트 파일**을 올려 두는 곳입니다.

## 처음 설치

1. 아래 링크를 누르면 최신 설치 파일(`biseo-setup.zip`)이 내려받아집니다.
   **https://github.com/boku109108-sys/biseo-updates/releases/latest/download/biseo-setup.zip**
   - 브라우저가 "일반적으로 다운로드되지 않는 파일"이라고 하면 [⋯] → [유지]를 누르세요.
2. 받은 zip을 마우스 오른쪽 버튼으로 눌러 **[모두 압축 풀기]** — `C:\Biseo`처럼 다운로드 폴더 밖에 푸는 것이 좋습니다.
3. 풀린 폴더의 **`설치하기`**를 더블클릭 ("PC 보호" 창이 뜨면 [추가 정보] → [실행]).
4. 업무비서 첫 화면에서 본인 Claude 계정으로 로그인.

## 자동 업데이트

- 한 번 설치하면, 업무비서가 켜질 때 이곳의 새 버전을 확인해 **스스로 바꿉니다.** 켜져 있는 동안 새 버전이 나오면 화면 위 "새 기능이 준비됐어요"에서 [지금 적용]을 누르면 됩니다.
- 모든 업데이트는 배포자만 가진 열쇠로 **서명**되어 있고, 업무비서는 서명이 맞는 것만 받아들입니다.
- 내려오는 것은 프로그램 파일뿐이며, 사용자의 문서·설정·작업 기록은 어디에도 올라가지 않습니다.
